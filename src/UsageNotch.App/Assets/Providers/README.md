# Provider logos

These original images identify the providers in Peak's usage rings and expanded cards. A small dark backing keeps the white Codex mark and warm Claude mark visible on custom notch colors. The images are embedded in the application; displaying them makes no network request.

- `Codex.png`: OpenAI's [Codex extension listing](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt), retrieved October 4, 2026. Original publisher asset: `https://openai.gallerycdn.vsassets.io/extensions/openai/chatgpt/26.5928.31416/1790813171325/Microsoft.VisualStudio.Services.Icons.Default`.
- `Claude.png`: the icon from [Claude's official site](https://claude.com/), retrieved October 4, 2026, at `https://claude.com/icon.png`.

OpenAI, Codex, Claude, and their marks belong to their respective owners. Peak is an independent utility and is not affiliated with either provider.
