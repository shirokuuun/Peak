# Freeware release checklist

- Confirm no activation, account, expiry or device limits; sample data requires --demo.
- Confirm publisher neorangel, support peakforwindows.support@gmail.com, website origin and policy version.
- Preserve provider consent, preferences/custom-path migration, bounded retention and safe restoration backups.
- Run Release build/tests; inspect self-contained x64 runtime, bridge, policies and full dependency license texts.
- Reject secrets, observations, paid configuration and debug artifacts from packages.
- Produce versioned installer, portable ZIP, notes, hashes and release metadata.
- State unsigned status accurately; optionally add trusted timestamped signatures later.
- Preserve source repository visibility and publish binary-only downloads in Peak-releases.
- Verify anonymous downloaded bytes and identical app/site policies before enabling website downloads.
- Verify Vercel production buttons, contact, canonical URLs and indexing.
- Record further clean-machine, update/uninstall and live-provider checks separately.
- Owner: verify mailbox receipt, enable two-step verification and apply the stated support retention practice.
